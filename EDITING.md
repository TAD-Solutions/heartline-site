# Editing the site from Claude Code

1. Open Claude Code (claude.ai/code, or the desktop app) and connect your GitHub account once.
2. Open the repo TAD-Solutions/heartline-site.
3. Say what you want in plain words, for example: "On the About page, replace the draft founder paragraphs with this text: ..." or "Change the home page sub-line to ...".
4. Claude edits the file and asks to commit and push. Say yes.
5. About a minute later, open the page at https://heartline.productions/about (or whichever page) and check it.

Claude reads CLAUDE.md in this repo, which lists where each page lives and what to leave alone.

If something looks wrong after a change, tell Claude "undo the last change and push" and the site goes back.
